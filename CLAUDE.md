# hello-page

Temporary one-page intro site for lavanyaaa.com, hosted on Vercel. It exists
as a practice run for the deploy pipeline (Vite + React + Tailwind on
Vercel) before the real portfolio site is built — not the final design.

## Stack

- Vite
- React
- Tailwind CSS (via the official `@tailwindcss/vite` plugin)
